Sobre o projeto

O que é o TdB Impact Engine?

É uma proposta de plataforma para organizar informações sobre doadores, empresas e parceiros da Turma do Bem.

Qual problema o projeto busca resolver?

A proposta busca centralizar informações e facilitar o acompanhamento de doações e oportunidades de parceria.

Posso fazer uma doação pelo site?

Não. Este site é um projeto acadêmico e não recebe doações.

A inteligência artificial já está funcionando?

Não. O uso de inteligência artificial é uma possibilidade para uma etapa futura do projeto.

Os dados apresentados são reais?

Não. Os dados usados nas demonstrações são apenas exemplos.
